# Puzzle Pop (Milestone 4): hand-over notes

**Files** (`frontend/src/playzone/games/puzzlePop/`): `engine.js` (the Match-3 rules, pure code), `levels.js` (5 worlds, 25 levels as data), `progress.js` (local progress, the service boundary), `controller.js` (state machine, input and the animation sequencer), `Scene.jsx` (React Three Fiber board), `Mascot.jsx` (LAXBOT puzzle assistant), `PuzzlePopGame.jsx` (canvas, HUD, input, overlays). Tests: `frontend/scripts/test-puzzle-pop.mjs` (run by `npm run test:game`). `catchTheStars/audio.js` gained a few effects (select, bad swap, rocket, boom, rainbow, pop).

**How a move works.** `playMove(state, a, b)` resolves a whole move at once and returns ordered steps (swap, clear, gravity, collect, reshuffle, end). The controller replays them as animations and ignores every tap, swipe and key until the last step has finished, so input can never reach a board that is still resolving. Everything is deterministic for a given level, seed and moves.

**Rules.** 8 x 8 board, six crystal cuts (ruby, sapphire, emerald, topaz, amethyst, rose quartz), horizontal and vertical lines of 3+. Starting boards never contain a match and always have a valid move; when none is left the ordinary crystals are reshuffled (power-ups, chests and blocks stay). Overlapping lines (T, L, cross) are one group and are scored once. Power-ups: 4 in a line = Rocket (a horizontal line makes a row rocket, a vertical line a column rocket), T or L = Bomb (3 x 3), 5 in a line = Rainbow. Combinations by swapping: Rocket + Rocket (row and column), Rocket + Bomb (three rows and three columns), Bomb + Bomb (5 x 5), Rainbow + normal crystal (every crystal of that colour), Rainbow + power-up (every crystal of that colour becomes that power-up and all fire), Rainbow + Rainbow (the whole board). Power-ups caught inside another effect set it off in turn.

**Scoring (one place: `SCORE` in `engine.js`).** Match of 3 +30, of 4 +60, of 5 or more +100 (by the longest line of a group); T / L shapes +10 for each crystal beyond the longest line; each crystal cleared by a power-up +10; special combination +150; each cascade step after the first adds +30 x (step - 1); level complete +200 and +20 per move left. Stars: finish = 1, a quarter of the moves left = 2, half left = 3.

**Obstacles and objectives.** Ice under tiles (clear a crystal on it to remove a layer), coral / crystal blocks (they fall, cannot be swapped, break after 1 or 2 hits from matches next to them or from a power-up), treasure chests (fall, collected on the bottom row, never destroyed). Objectives: reach a score, collect a colour, break all ice, bring all chests down, break all blocks, set off power-ups, make special combinations, a cascade of a given length in one move, set off Rainbows. A level is won only when ALL are met; moves running out is a failed level.

**Hints** (World 1 only, a light-bulb button) highlight the best valid swap; they never play it.

**Progress** is saved in `localStorage` (`lax360-playzone-puzzle-pop-v1`) through `progress.js` only: completion, best score and stars per level; a level opens when the previous one is completed. The best score also feeds the shared local record. To add a backend later, replace the bodies of `getProgress`, `saveLevelResult`, `isUnlocked` and `resetProgress`. Nothing is sent anywhere and nothing is ranked.

**Assets.** No new dependency (three, @react-three/fiber and three's `RoomEnvironment` are already used). Crystals, power-ups, chests and blocks are built from geometry in code; reflections come from a generated environment map; sound is synthesised (no audio files, nothing to license). **LAXBOT is a PLACEHOLDER** (primitive shapes with the Puzzle Wizard hat; moods: idle, happy, excited, encouraging, victory, fail), not production character art; replace it as described in `PLAYZONE_ASSETS.md`.

**Awaiting the backend:** server-side progress, official leaderboards and validated scores, cloud save.
